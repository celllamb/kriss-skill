# User-approved optional visual variants

> Design-reference approval is not native-export certification. This RC restores the original master artwork and title defaults;
> body pattern geometry is preserved except V10, whose dark emphasis is now a body panel. Consult `pattern-support.json` and `release-status.md`
> for measured gate results. Do not deliver a blocked pattern as a finished deck.


The canonical patterns remain the default. The following variants are approved as optional references and are stored separately in `references/approved-visual-variants.html`.

These variants are **not** source-native variants. They are generic variants derived from the KRISS reference vocabulary. Use them only when they improve clarity and do not replace the 25 canonical reference patterns by default.

## Excluded generic variants

The following generic variants remain excluded unless explicitly approved later: `full-width-diagram`, `timeline`, `annotated-screenshot`, `line-process`.

## Source-native approved variants

Approved source-native optional variants are stored separately in `references/source-native-visual-variants.html` and summarized in `references/source-native-visual-variants.md`. All S01–S13 are approved optional variants.
