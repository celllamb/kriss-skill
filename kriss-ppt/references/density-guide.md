# Density — content planning rather than global resizing

Use compact, standard and expanded as planning annotations, not permission for the
runtime to rewrite every component. Select an appropriate reference pattern and
content density before export. Reference geometry stays the default.

Use `preserve` for reference-authored boxes, `content-fit` when intrinsic sizing is
intentional, and `uniform` for explicit peers. Short content by itself is not a
reason to erase a fixed height. Missing space should first be addressed by content
organization or an appropriate reference variant, not invisible native font shrink.

Overflow relief follows the measured adaptive contract. Unresolved pressure is
reported. Layout balance and excessive whitespace are review items; do not turn
all subjective density judgments into automatic geometry rewrites.
